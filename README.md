🚗 Electric Vehicle Sales Analysis | Power BI Dashboard 
I recently explored an electric vehicle dataset to sharpen my data analysis skills and built an interactive dashboard using Power BI. What started as a simple practice exercise turned into some interesting insights.
📊 Key Insights:
2-Wheelers dominate the EV market with ~253K total sales compared to ~19K for 4-wheelers.
Top manufacturers like Hero Electric and Okinawa contribute significantly to total sales.
State-wise leaders include Maharashtra, Karnataka, and Tamil Nadu in EV adoption.
Monthly trends show variations in demand, indicating possible seasonality.
Several states have low adoption, highlighting untapped market opportunities.
🛠️ What I worked on:
Data modeling (fact & dimension tables)
Writing DAX measures for KPIs and comparisons
Building interactive dashboards with slicers (Year, State)
Visualizing trends using bar charts, line charts, and tables
💡 This project reinforced how even a practice dataset can uncover valuable business insights when approached with a data-driven mindset.
